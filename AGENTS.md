Preserve the user's source-selection and creative rules. Runtime or publishing changes are not permission to change artistic direction. Private source configuration and run provenance live outside this repository.

Use the existing Python CLI and fixed template. Run the relevant tests and build after edits. Verify rendered changes in a browser; verify the exact deployed revision after pushing. Keep tests focused on behavior and failure boundaries.
